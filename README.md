# Brogården - Camp & Hostel 🌲

This is the website for **Brogården**, a camp, hostel, and EFS church located in a scenic environment near the sea. The site is designed to provide visitors with information about accommodation, the surroundings, and booking in an inviting way.

🔗 **View the live site here:** [https://burra17.github.io/Brogarden-website/](https://burra17.github.io/Brogarden-website/)

## 📝 About the Project
The goal of the website is to convey the calm and community-focused atmosphere that Brogården represents. The design focuses on clarity, natural colors, and simple navigation so visitors can quickly find what they are looking for—from renting cottages to viewing the program activities.

### Key Features
* **Responsive Design:** Adapted for both mobile and desktop devices.
* **Hero Section:** Welcoming landing page with a large background image and a clear Call-to-Action (CTA).
* **Intuitive Navigation:** Menu for Home, Accommodation, Pictures, Contact, and Program.
* **Information:** Clear presentation of the facility's purpose and offerings.

## 🛠️ Technologies
The project is built with a focus on modern and clean code:
* **HTML5** - For structure and semantics.
* **CSS3** - For styling and layout (Flexbox/Grid).
* **JavaScript** - For interactivity.
* **GitHub Pages** - For hosting and publishing.
